Модуль предназначен для управления локальным блочным хранилищем на базе LVM. Он позволяет создавать StorageClass в Kubernetes с помощью ресурса [LocalStorageClass](cr.html#localstorageclass).

{{< alert level="info" >}}
Создание StorageClass для CSI-драйвера `local.csi.storage.deckhouse.io` пользователем запрещено.

Поддерживается режим доступа ReadWriteOnce (RWO). См. раздел [Режимы доступа и режимы тома](#режимы-доступа-и-режимы-тома).
{{< /alert >}}

{{< alert level="warning" >}}
Для снимков томов требуется модуль, поставляющий CRD группы `snapshot.storage.k8s.io`, — например [snapshot-controller](/modules/snapshot-controller/). Возможность работы со снимками томов доступна только в коммерческих редакциях Deckhouse Kubernetes Platform и только при использовании LVM-thin томов.
{{< /alert >}}

## Как работает модуль

Модуль `sds-local-volume` использует локальные диски узлов кластера для создания блочного хранилища на базе LVM.

Модуль поддерживает два режима работы: **LVM (Thick)** и **LVM-thin**. Подробнее о различиях между режимами см. в [FAQ](./faq.html#когда-следует-использовать-lvm-а-когда-lvm-thin).

## Режимы доступа и режимы тома

Тома модуля — это логические тома на дисках одного узла, поэтому использовать их можно только с одного узла.

- Режим доступа `ReadWriteOnce` поддерживается. Том в этом режиме можно также смонтировать на этом узле только для чтения.
- Режимы доступа `ReadWriteOncePod`, `ReadWriteMany` и `ReadOnlyMany` не поддерживаются.
- Поддерживаются оба режима тома: `volumeMode: Filesystem` (файловая система) и `volumeMode: Block` (сырое блочное устройство).

Если PersistentVolumeClaim запрашивает неподдерживаемый режим доступа, драйвер отказывается создавать том. PersistentVolumeClaim остаётся в состоянии `Pending`, а в его событиях появляется `ProvisioningFailed` с причиной отказа. Проверка действует только при создании новых томов; уже существующие тома не изменяются.

## Когда использовать модуль

Модуль `sds-local-volume` подходит для следующих сценариев:

- требуется максимальная производительность хранилища, сравнимая с производительностью локальных дисков (режим LVM (Thick));
- приложениям нужен быстрый доступ к данным на локальных дисках узлов без сетевых задержек;
- требуется использовать дисковое пространство за счёт выделения томов по требованию (режим LVM-thin).

Модуль не подходит для сценариев, где требуется:
- сетевое хранилище с возможностью миграции томов между узлами;
- репликация данных между узлами.

## Системные требования и рекомендации

Модуль имеет следующие системные требования и рекомендации:

- рекомендуется использовать стандартные ядра Linux, входящие в состав [поддерживаемых дистрибутивов](/products/kubernetes-platform/documentation/v1/reference/supported_versions.html#linux);
- не рекомендуется использовать другие решения SDS (Software Defined Storage) для предоставления дисков SDS для Deckhouse Kubernetes Platform.
